# wsl-linux-toolbox

Colección de herramientas en shell para gestionar entornos de desarrollo en WSL y Linux.

## Herramientas

| Herramienta | Descripción |
|-------------|-------------|
| [pymgr](pymgr/) | Gestor de versiones de Python compiladas desde código fuente |

## Instalación rápida

```bash
git clone git@github.com:ManoloMORALES123/wsl-linux-toolbox.git ~/toolbox
cd ~/toolbox
./install.sh
source ~/.bashrc
```

## Entorno probado

- WSL2 con Ubuntu / Debian
- Linux nativo (Debian/Ubuntu, Fedora/RHEL, Arch, openSUSE)
- macOS (con Homebrew)
